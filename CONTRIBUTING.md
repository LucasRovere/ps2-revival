# Contributing

Thanks for helping. Short version:

1. Read [AGENTS.md](AGENTS.md); its hard rules apply to humans too:
   no game data and nothing game-specific in the repo (per-game recipes and
   notes live in `local/games/<serial>/`), MIT-compatible code only, verify
   before claiming.
2. Check [docs/roadmap.md](docs/roadmap.md) for the next tasks and
   [docs/decisions.md](docs/decisions.md) before changing direction.
3. Keep docs in sync with your change (roadmap status, decisions; game notes locally).
4. Test on real data you own and describe what you tested in the PR.
5. Small PRs with clear titles (`textures: ...`, `extract: ...`, `docs: ...`).

New game? See [docs/games.md](docs/games.md).
Bug report? Include the serial, tool command, full output and PCSX2 version.
